# Projeto BAEP — 18º BPM/M Virtual

Site institucional do projeto de implantação BAEP para a Grande São Paulo.

## Executar localmente

Requisitos: Node.js 22.13 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

## Gerar versão de produção

```bash
pnpm build
```

## Publicação

O projeto pode ser mantido em um repositório GitHub e conectado a uma plataforma compatível com aplicações Next.js, como Vercel ou Cloudflare. O repositório contém a configuração usada pela hospedagem atual.

## Aviso

Projeto virtual independente, sem vínculo com órgãos públicos reais.
